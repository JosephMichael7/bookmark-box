# bookmark-box

A Base Mini App for onchain bookmarks.

## Overview

`bookmark-box` is a small application focused on saving and organizing bookmarks in an onchain context.

The project is intended to provide a clean starting point for building a bookmark experience as a Base Mini App.

Repository: <https://github.com/JosephMichael7/bookmark-box.git>

## Features

- Base Mini App project identity
- Bookmark-focused user experience
- Onchain bookmark concept
- Simple project structure for continued development
- Suitable foundation for experimenting with bookmark storage and discovery flows
